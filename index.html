Capstone: Research Assistant Agent

ทั้งซีรีส์สร้างโปรเจกต์เดียวกันต่อเนื่อง คือ agent ผู้ช่วยค้นคว้างานวิจัยที่ค้นหาและอ่าน paper แล้วเขียนรายงานให้ แต่ละ module เพิ่มความสามารถให้มันหนึ่งอย่าง

EP05 · tool-use + ReAct ✓ → M2 · harness → M3 · RAG → M4 · memory → M5 · MCP + skills → M6 · multi-agent → M7 · eval → M8 · UI

เส้นทางการเรียน

เรียงตามลำดับที่แนะนำ ตอนที่ยังไม่เปิดจะทยอยออกทาง playlist · เลข § ในวงเล็บคือ section ในตำรา

M0 ก่อนเริ่ม: LLM ที่คนสร้าง agent ต้องรู้ พื้นฐานที่จำเป็น ข้ามได้ถ้าเคยใช้ LLM API มาแล้ว

EP01

LLM ทำงานอย่างไร (ฉบับคนสร้าง agent) เร็วๆ นี้ token, context window, temperature กระทบ agent อย่างไร · ch1 · ≈30 นาที

EP02

Prompt, structured output และ hallucination เร็วๆ นี้ ทำไม agent ต้องการ JSON schema · ch1, §19.3 · ≈30 นาที

M1 Agent คืออะไร และออกแบบอย่างไร จบ module แล้วเลือกได้ว่างานไหนใช้ workflow พอ งานไหนต้องเป็น agent

EP03

จาก chatbot สู่ agent เร็วๆ นี้ 5 ความท้าทายของ agent และแผนที่ทั้งซีรีส์ · ch15 · ≈12 นาที

EP04

Workflow Patterns พร้อมเรียน chaining · routing · parallelization · orchestrator-workers · evaluator-optimizer · §19.1 · 5 lab

EP05

Autonomous Agent Patterns พร้อมเรียน ReAct · planning · reflection · tool-use · LangGraph · §19.2 · 5 lab

EP06

หลักออกแบบ + เลือก pattern เร็วๆ นี้ ต้นทุนเทียบคุณภาพ และ decision matrix · §19.3–19.4 · ≈20 นาที

M2 Harness: ระบบปฏิบัติการของ agent สร้าง harness ตัวแรกของ capstone

EP07

Context window management เร็วๆ นี้ sliding window, summarization เมื่อบทสนทนายาวเกิน context · §18.1–18.3

EP08

Tools, state และ error handling เร็วๆ นี้ retry, guardrail, checkpoint · §18.4, 18.6–18.8

EP09

สร้าง production harness เร็วๆ นี้ รวมทุกอย่างเป็น harness ของ research agent · §18.10

M3 ความรู้: RAG ให้ agent ตอบจากเอกสารของเราเอง

EP10

RAG พื้นฐาน เร็วๆ นี้ chunking และ retrieval บน paper · §16.1–16.4

EP11

Advanced & Agentic RAG เร็วๆ นี้ agent ตัดสินใจเองว่าจะค้นอะไร เมื่อไร และวัดผล RAG · §16.5, 16.7–16.9

M4 ความจำ agent ที่จำสิ่งที่ทำมาแล้วได้

EP12

Agent memory เร็วๆ นี้ ความจำระยะสั้น ระยะยาว episodic และการเก็บ ค้น ลืม · ch17

M5 เชื่อมโลกภายนอก: MCP และ Skills ต่อ agent เข้ากับ tool และความรู้แบบมาตรฐาน

EP13

MCP เร็วๆ นี้ ทำไมต้องมีมาตรฐาน tool และสร้าง MCP server สำหรับค้น paper · ch21

EP14

Agent Skills เร็วๆ นี้ skill ต่างจาก tool และ fine-tuning อย่างไร · ch22

M6 หลาย agent ทำงานร่วมกัน แบ่งงานให้ทีม agent

EP15

Multi-agent systems เร็วๆ นี้ เมื่อไรควรใช้หลาย agent และ architecture แบบ supervisor + workers · ch24

EP16

A2A protocol เร็วๆ นี้ agent คุยกันข้ามระบบอย่างไร และ A2A ต่างจาก MCP ตรงไหน · ch23

M7 วัดผลและความน่าเชื่อถือ รู้ได้อย่างไรว่า agent ดีขึ้นจริง

EP17

ประเมิน agent เร็วๆ นี้ metric สำหรับงานหลายขั้นและ LLM-as-judge · ch14, ch20

EP18

Testing & observability เร็วๆ นี้ debug agent ที่ทำไม่เหมือนเดิมทุกรอบด้วย trace และ test suite · §25.5–25.6

M8 Framework, production และ UI ปิดท้ายด้วย capstone ที่มี UI ใช้งานได้จริง

EP19

Agent frameworks เร็วๆ นี้ เลือก framework ไหน ต่างกันอย่างไร · ch25

EP20

Agentic UI เร็วๆ นี้ streaming และ human-in-the-loop · research agent พร้อม UI · ch26
