▶ Video · ✏️ Starter in Colab · ✅ Solution in Colab · Back to EP02 Prompt, Structured Output และ Hallucination

Models do not answer the same way every time, so your own run may differ from this page.

In the theory video we saw that a prompt is a job sheet: the clearer it is, the less the model has to guess. In this lab our teaching assistant classifies student emails as question / extension / complaint, and we see for ourselves how differently each kind of prompt behaves.

What you’ll learn

  1. zero-shot: just the instruction — right answers, but the format doesn’t match
  2. few-shot: add examples, and the model answers in the same format every time
  3. the six-part job sheet + system prompt + delimiters, against an instruction hidden in an email
  4. chain-of-thought: helps multi-step problems, but is wasted on single-step tasks

The emails in this lab are simulated data written for teaching; every model answer comes from a real run. (The video uses Thai emails and Thai labels; this English notebook uses English ones, so your outputs will differ in wording.)

Reference: Haggai Roitman, The Hitchhiker’s Guide to Agentic AI, §1.13 — CC BY-SA 4.0

1. Calling Gemma through OpenRouter

Why google/gemma-4-26b-a4b-it — follows instructions well, can answer to a JSON schema (used in Labs 2–4), and returns token probabilities (used in Lab 3)

Why we pin the provider to Parasail — we tested this episode’s JSON schemas on 7 providers (2026-11-09): Parasail always returned the right format and also returns probabilities; some providers printed blank lines until they hit max_tokens

Not free, but very cheap: all of EP02 costs a few cents · the :free version doesn’t suit this episode (tested 2026-11-09: 4 of 6 calls got 429 “rate-limited”, and the other 2 ignored the JSON schema and answered in plain text · re-tested 2026-11-15: all 6 calls got 429)

import os
from openai import OpenAI

def load_key():
    try:  # Google Colab Secrets
        from google.colab import userdata
        return userdata.get("OPENROUTER_API_KEY")
    except ImportError:
        pass
    from dotenv import load_dotenv
    load_dotenv()
    return os.environ["OPENROUTER_API_KEY"]

client = OpenAI(base_url="https://openrouter.ai/api/v1", api_key=load_key())
MODEL = "google/gemma-4-26b-a4b-it"
PROVIDER = {"order": ["parasail/bf16"], "allow_fallbacks": False}
EXTRA = {"reasoning": {"enabled": False}, "provider": PROVIDER}
def ask(messages, **kw):
    resp = client.chat.completions.create(model=MODEL, messages=messages, extra_body=EXTRA, **kw)
    return resp.choices[0].message.content, resp.usage.completion_tokens
