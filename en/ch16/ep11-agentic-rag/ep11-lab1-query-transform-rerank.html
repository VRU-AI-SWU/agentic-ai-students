1. Three models: one answers, one embeds, one re-ranks

The answering model google/gemma-4-26b-a4b-it — the same model as every episode, pinned to Makora. USD 0.09 per million input tokens and USD 0.28 per million output tokens · The :free version doesn’t work (tested 2026-11-22: 3 out of 3 calls got 429 “rate-limited”)

The embedding model qwen/qwen3-embedding-8b — the same as EP10, pinned to Nebius

The re-ranker qwen/qwen3-reranker-8b — an open cross-encoder from the same family, called through OpenRouter’s /api/v1/rerank endpoint with the same key, pinned to Fireworks · about USD 0.20 per million tokens (re-ranking 20 chunks ≈ 0.2 cents) · The book uses a BGE re-ranker through sentence-transformers, which downloads the model to your machine — here we call an API instead, no GPU needed

Every request’s real cost is added up in COST

import os, urllib.request, requests
import numpy as np
from openai import OpenAI
from pypdf import PdfReader
from tokenizers import Tokenizer
from concurrent.futures import ThreadPoolExecutor

def load_key():
    try:  # Google Colab Secrets
        from google.colab import userdata
        return userdata.get("OPENROUTER_API_KEY")
    except ImportError:
        pass
    from dotenv import load_dotenv
    load_dotenv()
    return os.environ["OPENROUTER_API_KEY"]
MODEL = "google/gemma-4-26b-a4b-it"
EXTRA = {"reasoning": {"enabled": False},
         "provider": {"order": ["makora"], "allow_fallbacks": False}}
EMBED_MODEL = "qwen/qwen3-embedding-8b"
EMBED_EXTRA = {"provider": {"order": ["nebius"], "allow_fallbacks": False}}
RERANK_MODEL = "qwen/qwen3-reranker-8b"
RERANK_PROVIDER = {"order": ["fireworks"], "allow_fallbacks": False}
KEY = load_key()
client = OpenAI(base_url="https://openrouter.ai/api/v1", api_key=KEY, max_retries=5)
COST = {"chat": 0.0, "embed": 0.0, "rerank": 0.0}

def ask(prompt):
    r = client.chat.completions.create(model=MODEL, temperature=0, extra_body=EXTRA,
                                       messages=[{"role": "user", "content": prompt}])
    COST["chat"] += r.usage.cost
    return r.choices[0].message.content

def embed(texts):
    vectors = []
    for i in range(0, len(texts), 64):
        r = client.embeddings.create(model=EMBED_MODEL, input=texts[i:i + 64],
                                     extra_body=EMBED_EXTRA)
        COST["embed"] += r.usage.cost
        vectors += [d.embedding for d in r.data]
    V = np.array(vectors)
    return V / np.linalg.norm(V, axis=1, keepdims=True)

**Section 4.2: Retrieval-Augmented Generation (RAG)**

To understand the mechanics of Retrieval-Augmented Generation, Roitman employs a foundational analogy: the distinction between a student taking an exam from memory versus a student taking an "open-book" exam. In this comparison, the Large Language Model (LLM) represents the student’s innate intelligence and linguistic capability. While a standard LLM relies solely on its internal weights (memory), RAG provides the model with an external textbook (the retrieval source). By allowing the agent to "look up" specific, real-time data before formulating a response, RAG transforms the model from a closed system into an informed researcher.

def variants(query, extra=""):
    out = ask("Write 3 different search queries that could find the answer to this question "
              f"in a textbook.{extra} One per line, no numbering, nothing else.\n\nQuestion: " + query)
    return [line.strip(" -•\t") for line in out.splitlines() if line.strip()][:3]

def rrf(lists, k=60):
    score = {}
    for order in lists:
        for rank, i in enumerate(order, 1):
            score[i] = score.get(i, 0) + 1 / (k + rank)
    return sorted(score, key=score.get, reverse=True)

5. Re-ranking with a cross-encoder

First-stage search with embeddings (fast) → hand the top 20 chunks to a cross-encoder, which reads each question–chunk pair and scores it again (§16.5.2). A cross-encoder has no precomputed vectors, so it can’t search the whole library, but it’s more accurate

def rerank(query, order, n=20):
    top = order[:n]
    r = requests.post("https://openrouter.ai/api/v1/rerank",
                      headers={"Authorization": f"Bearer {KEY}"},
                      json={"model": RERANK_MODEL, "provider": RERANK_PROVIDER, "query": query,
                            "documents": [chunks[i]["text"] for i in top]}, timeout=60)
    r.raise_for_status()
    # ✏️ TODO 3 (▶ video 6:51): map each result's index (a position in top) back to the chunk number in the library
    data = r.json()
    COST["rerank"] += data["usage"]["cost"]
    return [___ for x in data["results"]], [x["relevance_score"] for x in data["results"]]

def rerank(query, order, n=20):
    top = order[:n]
    r = requests.post("https://openrouter.ai/api/v1/rerank",
                      headers={"Authorization": f"Bearer {KEY}"},
                      json={"model": RERANK_MODEL, "provider": RERANK_PROVIDER, "query": query,

    r.raise_for_status()
    data = r.json()
    COST["rerank"] += data["usage"]["cost"]
    return [top[x["index"]] for x in data["results"]], [x["relevance_score"] for x in data["results"]]
