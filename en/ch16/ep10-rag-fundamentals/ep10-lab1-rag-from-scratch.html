1. Two models: one answers, one embeds

The answering model google/gemma-4-26b-a4b-it — the same model as every episode, pinned to Makora as in EP08–EP09. USD 0.09 per million input tokens and USD 0.28 per million output tokens · The :free version doesn’t work (tested 2026-11-21: 3 out of 3 calls got 429 “temporarily rate-limited upstream”)

The embedding model qwen/qwen3-embedding-8b — Qwen’s open embedding model, called through OpenRouter with the same key. It returns vectors of 4,096 numbers, at USD 0.01 per million tokens (embedding our whole library costs about 0.05 cents). Pinned to the Nebius provider so the numbers are the same on every run

The usage.cost OpenRouter sends back is each request’s real cost — we add it up in COST and look at it at the end

EXTRA = {"reasoning": {"enabled": False},
         "provider": {"order": ["makora"], "allow_fallbacks": False}}
EMBED_MODEL = "qwen/qwen3-embedding-8b"
EMBED_EXTRA = {"provider": {"order": ["nebius"], "allow_fallbacks": False}}

COST = {"chat": 0.0, "embed": 0.0}

def ask(prompt):
    r = client.chat.completions.create(model=MODEL, temperature=0, extra_body=EXTRA,
                                       messages=[{"role": "user", "content": prompt}])
    COST["chat"] += r.usage.cost
    return r.choices[0].message.content

2. Asking without RAG

The textbook came out in 2026, after Gemma was trained — does the model know this book?

question = ("In Roitman's book The Hitchhiker's Guide to Agentic AI, "
            "what analogy does the RAG chapter use to explain RAG?")
print(ask(question))
In Roitman's book *The Hitchhiker's Guide to Agentic AI*, the analogy used to explain **Retrieval-Augmented Generation (RAG)** is that of an **open-book exam.**

Here is how the analogy breaks down:

*   **The LLM (Large Language Model) is the student:** The student has a vast amount of general knowledge and reasoning ability (the pre-training), but they might forget specific details, hallucinate facts, or lack access to information that was published after they finished studying.
*   **RAG is the textbook/reference material:** Instead of forcing the student to rely solely on their memory (parametric memory), RAG provides the student with a specific textbook or a set of notes (the external knowledge base) to look at during the exam.
*   **The Process:** When a question is asked, the "student" (LLM) first looks up the relevant passage in the "textbook" (Retrieval), reads it, and then uses their reasoning skills to write a perfect answer based on that specific information (Generation).

By using this analogy, Roitman illustrates that RAG doesn't change how "smart" the model is; rather, it changes what information the model has available to it at the moment it needs to answer a question.

def embed(texts):
    vectors = []
    for i in range(0, len(texts), 64):
        r = client.embeddings.create(model=EMBED_MODEL, input=texts[i:i + 64],
                                     extra_body=EMBED_EXTRA)
        COST["embed"] += r.usage.cost
        vectors += [d.embedding for d in r.data]
    V = np.array(vectors)
    return V / np.linalg.norm(V, axis=1, keepdims=True)

SYSTEM_PROMPT = """You are a helpful assistant. Answer the question using ONLY
the provided context. If the context does not contain enough information,
say so explicitly. Cite your sources using [Doc N] notation."""

def build_rag_prompt(query, chunks):
    context_str = "\n\n".join(
        f"[Doc {i+1}] (Source: {c['source']}, Page: {c.get('page', 'N/A')})\n{c['text']}"
        for i, c in enumerate(chunks))
    return f"""{SYSTEM_PROMPT}

Context:
{context_str}

Question: {query}

Answer:"""

def rag(query, k=3):
    hits = search(query, k)
    for score, c in hits:
        print(f"  retrieved page {c['page']}  ({score:.3f})")
    return ask(build_rag_prompt(query, [c for _, c in hits]))

Summary

Step What we saw in the lab
No RAG the model confidently said “open-book exam” — a phrase on no page of the book
Load + metadata textbook v1 pages 292–374 → 83 pages, each with source + page
Chunk 512 tokens, overlap 64 → 141 chunks
Embed car · automobile ≈ 0.94 but car · banana ≈ 0.58 (not 0) — the order matters more than the number
Retrieve + generate “library card”, citing [Doc 2], page 295 · legal documents: paragraph level, 1-sentence overlap

Retrieval misses the long question with the book’s title → the “library card” chunk falls to rank 8 → “not in the context”
