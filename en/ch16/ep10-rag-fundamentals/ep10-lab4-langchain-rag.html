from langchain_core.retrievers import BaseRetriever

def words(text):
    return re.findall(r"\w+", text.lower())

class OurBM25(BaseRetriever):
    docs: list
    k: int = 3

    def _get_relevant_documents(self, query, *, run_manager=None):
        bags = [Counter(words(d.page_content)) for d in self.docs]
        lens = [sum(bag.values()) for bag in bags]
        N, avgdl = len(bags), sum(lens) / len(bags)
        df = Counter(w for bag in bags for w in bag)
        k1, b = 1.5, 0.75
        scores = []
        for bag, dl in zip(bags, lens):
            s = 0.0
            for t in words(query):
                idf = math.log((N - df[t] + 0.5) / (df[t] + 0.5) + 1)
                s += idf * bag[t] * (k1 + 1) / (bag[t] + k1 * (1 - b + b * dl / avgdl))
            scores.append(s)
        best = np.argsort(-np.array(scores))[:self.k]
        return [self.docs[i] for i in best]

Q: How do I combine keyword search and embedding search? · pages [298, 311, 301]
A: You can combine keyword search (sparse scores) and embedding search (dense scores) using the following methods:

*   **Linear Combination:** A simple way to combine them is through a linear combination of the scores: $s_{hybrid}(d,q) = \alpha \cdot s_{dense}(d,q) + (1-\alpha) \cdot s_{sparse}(d,q)$ [Doc 1].
*   **Reciprocal Rank Fusion (RRF):** Because scores from different systems are not directly comparable, RRF can be used to combine results by operating on ranks rather than scores [Doc 1]. The formula is $RRF(d) = \sum_{r \in R} \frac{1}{k + rank_r(d)}$, where $R$ is the set of ranked lists (such as BM25 ranking and dense ranking) [Doc 1].
