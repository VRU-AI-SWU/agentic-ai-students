Agentic AI: From Foundations to Systems

Learn to build AI agents from the theory to working code. Every episode has a hand-drawn animated theory video, labs where we type the code line by line in Jupyter, a recap, and notebooks you can open in Google Colab right away. Adapted from the textbook The Hitchhiker’s Guide to Agentic AI (Roitman 2026).

How each episode works

🎬

Theory video — hand-drawn animation that explains the idea and the reasoning behind it before any code

💻

2–5 labs — the code typed line by line in Jupyter, with a ✏️ starter notebook (fill in the TODOs) and a ✅ solution

📖

Recap + reading page — a closing recap video, and a page on this site with diagrams, real lab output and review questions

Videos are narrated in Thai — turn on CC → English · every lab has an English notebook · watch in playlist order and the next video plays automatically

Capstone: Research Assistant Agent

The whole series grows one project: an agent that searches and reads research papers and writes a report. Each module gives it one new capability.

EP05 · tool-use + ReAct ✓ → M2 · harness → M3 · RAG → M4 · memory → M5 · MCP + skills → M6 · multi-agent → M7 · eval → M8 · UI

What you need

🐍

Basic Python — you can read and change functions, lists and dicts; no machine-learning background needed

🔑

An OpenRouter API key — the labs use Gemma 4 26B (open weights); one notebook run costs a few cents at most. Setup is in the README

🌐

A browser — open the notebooks in Google Colab; nothing to install

NoteAbout the content and license

This series is not a copy of the textbook: each episode answers one question or teaches one skill, and may draw on several chapters. Its core is Part V of the textbook (chapters 15–26); RL, alignment and reasoning training (Parts II–III) are not part of this series.

The original textbook is released under CC BY-SA 4.0, so this adaptation is released under CC BY-SA 4.0 as well.
