Models do not answer the same way every time, so your own run may differ from this page.

A good agent must be able to stop and evaluate itself. The textbook splits reflection into 3 levels:

  1. Output validation — “Is it correct? Did I forget anything?”
  2. Trajectory review — look back over the last k steps
  3. Strategy revision — “Am I solving the right problem?”

Reflexion keeps lessons from mistakes in a reflection memory and puts them into the next attempt’s prompt → it learns across attempts without updating any weights

Reference: Haggai Roitman, The Hitchhiker’s Guide to Agentic AI, §19.2.3 — CC BY-SA 4.0

import re

def parse_duration(s: str) -> float:
    """
    Converts a duration string like '1h30m' or '2d1h' into total minutes.
    Supported units: d (days), h (hours), m (minutes), s (seconds).
    Raises ValueError for invalid formats or unit-less strings.
    """
    s_clean = s.lower().replace(" ", "")
    if not s_clean:
        raise ValueError("Empty duration string")

    # Pattern matches: (number including decimals) followed by (one of d, h, m, s)
    # (\d+\.?\d*|\.\d+) handles formats like '1', '1.', '1.5', and '.5'
    pattern = r'(\d+\.?\d*|\.\d+)([dhms])'
    matches = list(re.finditer(pattern, s_clean))

    if not matches:
        raise ValueError("Invalid duration format or missing units")

    unit_map = {
        'd': 1440.0,
        'h': 60.0,
        'm': 1.0,
        's': 1/60.0
    }

    total_minutes = 0.0
    last_end = 0

    for m in matches:
        # If there is a gap between matches, the string contains invalid characters
        if m.start() != last_end:
            raise ValueError("Invalid duration format")
        
        val = float(m.group(1))
        unit = m.group(2)
        total_minutes += val * unit_map[unit]
        last_end = m.end()

    # If there is leftover text after the last valid match
    if last_end != len(s_clean):
        raise ValueError("Invalid duration format")

    return total_minutes
