Lab 1 — จาก chatbot เป็น agent

Lab walkthrough · EP03 จาก Chatbot สู่ Agent

หมายเหตุวิธีใช้หน้านี้

หน้านี้คือ notebook เฉลยของ lab นี้ทีละ cell พร้อม output จากการรันจริงตอนอัดคลิป ไว้อ่านทวนก่อนหรือหลังลงมือ cell ที่มี ✏️ TODO แสดงโค้ดแบบใน starter notebook ส่วนเฉลยเต็มอยู่ในกล่อง ดูเฉลย ลองเขียนเองก่อนค่อยเปิด

▶ วิดีโอ · ✏️ Starter ใน Colab · ✅ เฉลยใน Colab · กลับไปหน้า EP03 จาก Chatbot สู่ Agent

model ตอบไม่เหมือนเดิมทุกครั้ง output ที่คุณรันเองจึงอาจต่างจากหน้านี้

ในคลิปทฤษฎีเราเห็นว่า agent คือ LLM ที่ทำงานเป็นวง รับรู้ → คิด → ลงมือ ผ่าน tool โดยมี harness คุมอยู่รอบนอก lab นี้เราจะสร้างผู้ช่วยของวิชา AI301 ที่ตอบได้ว่า “อีกกี่วันสอบกลางภาค” และ จองห้องติวให้จริง — ด้วยโค้ดของเราเองทั้งหมด

สิ่งที่จะได้เรียน

  1. chatbot: เรียก model ครั้งเดียว — ตอบไม่ได้ จองไม่ได้
  2. tool: ฟังก์ชันปฏิทิน ดูห้องว่าง และจองห้อง + JSON schema ที่บอก model
  3. agent loop: harness ตัวแรกของเรา (วนจนเสร็จ หรือจนต้องถามคน)
  4. persistence: เก็บประวัติไว้ใน list จึงคุยต่อข้ามรอบได้
  5. safety: จำกัดจำนวนรอบ + ให้คนอนุมัติก่อนจอง (human-in-the-loop)

ปฏิทินและห้องติวใน lab นี้เป็น ข้อมูลจำลองที่เขียนขึ้นเพื่อการสอน (วันนี้ = 10 พ.ย. 2026) ส่วนคำตอบและการเรียก tool ของ model ทั้งหมดมาจากการรันจริง

1. เรียก Gemma ผ่าน OpenRouter

ทำไมใช้ google/gemma-4-26b-a4b-it — ทำตามคำสั่งภาษาไทยได้ดี และ เรียก tool ได้ (tool calling) ซึ่งเป็นหัวใจของ agent ใน lab นี้และ Lab 2

ทำไมล็อก provider เป็น DeepInfra — Parasail ที่ใช้ใน EP02 ไม่รองรับ tool เลย เราทดสอบ agent ของ lab นี้กับ 10 provider ที่รองรับ tool (2026-11-10): ส่วนใหญ่เดินขั้นตอนเหมือนกันทุกครั้ง แต่มีเจ้าหนึ่งตีความ “วันพฤหัสนี้” เป็นคนละวัน → เราล็อกไว้เจ้าเดียว (deepinfra/fp8) ให้ผลซ้ำได้

ไม่ฟรี แต่ถูกมาก: รันทั้ง lab หนึ่งรอบ ≈ 5,800 token ≈ 0.0006 ดอลลาร์ (ไม่ถึง 10 สตางค์) · รุ่น :free ใช้ไม่ได้ (ทดสอบ 2026-11-15: 6 ใน 6 ครั้งได้ 429 “rate-limited upstream”)

4. Agent loop = harness ตัวแรกของเรา

ในลูป จากคลิปทฤษฎี
ส่ง history + TOOLS ให้ model 💭 คิด
model ขอ tool → run_tool 🔧 ลงมือ
ผลของ tool กลับเข้า history 👀 รับรู้ (observation)
ไม่ขอ tool แล้ว → ตอบ / ถามคน 🏁 จบ / 🙋 ถามคน
max_steps 🛑 guardrail: วนได้ไม่เกินกี่รอบ

def run_agent(history, max_steps=MAX_STEPS):
    for step in range(1, max_steps + 1):
        msg = call_llm(history)
        if not msg.tool_calls:
            history.append({"role": "assistant", "content": msg.content})
            return msg.content
        history.append({"role": "assistant", "content": msg.content or "",
                        "tool_calls": [c.model_dump() for c in msg.tool_calls]})
        for call in msg.tool_calls:
            print(f"  🔧 {call.function.name}({call.function.arguments})")
            if call.function.name in NEEDS_APPROVAL:
                PENDING.append(call)
                continue
            result = run_tool(call)
            print(f"  👀 {result}")
            history.append({"role": "tool", "tool_call_id": call.id, "content": result})
        if PENDING:
            return "⏸ รออนุมัติ"
    return f"⚠️ หยุด: ครบ {max_steps} รอบ"
